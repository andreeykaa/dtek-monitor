# ⚡ ДТЕК Монітор

Telegram-бот, який стежить за графіком відключень **ДТЕК Київські електромережі**
за адресою користувача і пише, коли:

- змінюється графік на сьогодні;
- з'являється або змінюється графік на завтра.

Користувач натискає «Почати», вводить вулицю (бот пропонує точні назви з сайту ДТЕК)
і номер будинку — далі все автоматично. Одна людина — одна адреса.

## Як це влаштовано

| Частина | Де працює | Що робить |
|---|---|---|
| `worker/` | Cloudflare Workers (безкоштовно) | Відповідає в Telegram миттєво, зберігає адреси в базі D1 |
| `checker/` | GitHub Actions (безкоштовно) | Кожні 10 хв відкриває сайт ДТЕК, перевіряє адреси, розсилає зміни |

Особисті дані (адреси, Telegram ID) лежать лише в базі Cloudflare, у репозиторії їх немає.

## Налаштування (одноразово)

### 1. Секрети GitHub

**Settings → Secrets and variables → Actions → New repository secret**:

| Назва | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID з Cloudflare |
| `CLOUDFLARE_API_TOKEN` | API-токен Cloudflare: шаблон «Edit Cloudflare Workers» + дозвіл **Account → D1 → Edit** |
| `GH_DISPATCH_TOKEN` | *(необов'язково, але бажано)* — див. нижче |

**`GH_DISPATCH_TOKEN`** дозволяє боту одразу запускати перевірку нової адреси
(1–2 хв замість до 10 хв). Як створити:
GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
- *Repository access*: **Only select repositories** → `dtek-monitor`;
- *Permissions → Repository permissions → Actions*: **Read and write**;
- Generate → скопіювати.

### 2. Розгортання

**Actions → «Розгортання бота» → Run workflow.**

Через ~1 хв бот працює: напишіть йому `/start`. Після розгортання автоматично
запуститься перша перевірка, яка завантажить список вулиць для пошуку.

Далі розгортання запускається само при кожній зміні в `worker/`.

### 3. Перевірка, що все працює

- **Actions → «Перевірка графіка»** — запуски кожні ~10 хв, зелена галочка = успіх.
  У журналі кроку «Перевірити графіки» видно кількість користувачів і надісланих повідомлень.
- Якщо запуск червоний — GitHub надішле лист; текст помилки в журналі.

## Команди бота

- **📅 Графік** / `/status` — поточний графік
- **📍 Змінити адресу** / `/address`
- `/stop` — відписатися, `/start` — підписатися знову

## Корисне знати

- Розклад GitHub може запізнюватись на 5–15 хв у години пік.
- GitHub вимикає розклад у неактивних репозиторіях через 60 днів — workflow «Не засинати»
  раз на місяць не дає цьому статися. Якщо все ж прийде лист про вимкнення —
  Actions → «Перевірка графіка» → **Enable workflow**.
- Локальна версія для Windows (лише для себе) — `dtek_monitor.py` поза цим репозиторієм.
