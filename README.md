# ⚡ ДТЕК Монітор

Telegram-бот, який стежить за графіком відключень **ДТЕК Київські електромережі**
за адресою користувача і пише, коли:

- змінюється графік на сьогодні;
- з'являється або змінюється графік на завтра.

Користувач натискає «Почати», вводить вулицю (бот пропонує точні назви з сайту ДТЕК)
і номер будинку — далі все автоматично. Одна людина — одна адреса.

## Як це влаштовано

| Частина | Де працює | Що робить |
|---|---|---|
| `worker/` | Cloudflare Workers (безкоштовно) | Відповідає в Telegram миттєво, зберігає адреси в базі D1 |
| `checker/` | GitHub Actions (безкоштовно) | Відкриває сайт ДТЕК, перевіряє адреси, розсилає зміни |

Перевірку кожні **10 хв** запускає Cloudflare Cron (`worker/wrangler.toml`), а також бот — одразу після введення нової адреси.
Розклад GitHub Actions не використовується: він ненадійний.

Особисті дані (адреси, Telegram ID) лежать лише в базі Cloudflare, у репозиторії їх немає.

## Налаштування (одноразово)

### 1. Секрети GitHub

**Settings → Secrets and variables → Actions → New repository secret**:

| Назва | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID з Cloudflare |
| `CLOUDFLARE_API_TOKEN` | API-токен Cloudflare: шаблон «Edit Cloudflare Workers» + дозвіл **Account → D1 → Edit** |
| `GH_DISPATCH_TOKEN` | **обов'язково** — через нього запускаються всі перевірки, див. нижче |
| `ADMIN_CHAT_ID` | *(бажано)* ваш Telegram chat_id — бот попередить, якщо перевірки перестануть запускатися
  або за 7 днів до закінчення `GH_DISPATCH_TOKEN` |
| `HEALTHCHECK_URL` | *(бажано)* адреса «сторожа» healthchecks.io — див. нижче |

**`GH_DISPATCH_TOKEN`** дозволяє Cloudflare запускати перевірки на GitHub. Як створити:
GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
- *Repository access*: **Only select repositories** → `dtek-monitor`;
- *Permissions → Repository permissions → Actions*: **Read and write**;
- *Expiration*: краще 1 рік або без терміну — коли токен закінчиться, перевірки зупиняться
  (з `ADMIN_CHAT_ID` бот про це напише);
- Generate → скопіювати.

**`HEALTHCHECK_URL`** — «сторож»: після кожної вдалої перевірки бот відмічається на
[healthchecks.io](https://healthchecks.io); якщо відмітки довго немає — сервіс сам повідомить вас.
Це ловить будь-який збій: Cloudflare, GitHub, токен, сайт ДТЕК.
1. Зареєструватися на healthchecks.io (безкоштовно) → **Add Check**.
2. *Schedule*: **Period 10 minutes**, **Grace 20 minutes**.
3. *Integrations* → додати **Telegram** (або залишити Email).
4. Скопіювати *Ping URL* (`https://hc-ping.com/...`) у секрет `HEALTHCHECK_URL`.

### 2. Розгортання

**Actions → «Розгортання бота» → Run workflow.**

Через ~1 хв бот працює: напишіть йому `/start`. Після розгортання автоматично
запуститься перша перевірка, яка завантажить список вулиць для пошуку.

Далі розгортання запускається само при кожній зміні в `worker/`.

### 3. Перевірка, що все працює

- **Actions → «Перевірка графіка»** — запуски кожні 10 хв, зелена галочка = успіх.
  У журналі кроку «Перевірити графіки» видно кількість користувачів і надісланих повідомлень.
- Якщо запуск червоний — GitHub надішле лист; текст помилки в журналі.

## Команди бота

- **📅 Графік** / `/status` — поточний графік
- **📍 Змінити адресу** / `/address`
- `/stop` — відписатися, `/start` — підписатися знову
- `/delete` — повністю видалити свої дані

## Корисне знати

- Інтервал перевірки змінюється в `worker/wrangler.toml` (`crons`).
- Звичайна перевірка робить лише одне завантаження сторінки ДТЕК: графік усіх груп є на ній одразу.
  Окремі запити по вулицях — тільки для нових адрес і для кількох вулиць за раз раз на 12 год
  (на випадок, якщо ДТЕК змінить групу будинку).
- Локальна версія для Windows (лише для себе) — `dtek_monitor.py` поза цим репозиторієм.
